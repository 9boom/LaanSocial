ลาน มหาวิทยาลัย

ศูนย์กลางแชททุกมหาวิทยาลัยออนไลน์ รวมในที่เดียว

กฎระเบียบชุมชน

อัปเดตล่าสุด: กันยายน 2569

1. เจตนารมณ์และบทนำ

ลาน มหาวิทยาลัย สร้างขึ้นเพื่อเป็นพื้นที่กลางออนไลน์ที่เปิดกว้าง ปลอดภัย และสร้างสรรค์สำหรับนักศึกษาและบุคลากรจากทุกมหาวิทยาลัย เพื่อการพูดคุย แลกเปลี่ยนข้อมูล ปรึกษาหารือ และสร้างมิตรภาพร่วมกัน

เพื่อให้สังคมแห่งนี้คงไว้ซึ่งความสงบเรียบร้อยและความเคารพซึ่งกันและกัน ผู้ใช้งานทุกคนต้องปฏิบัติตามกฎระเบียบชุมชนฉบับนี้ การเข้าใช้งานแพลตฟอร์มถือว่าท่านรับทราบและยินยอมผูกพันตามกฎระเบียบนี้โดยสมบูรณ์

2. แนวทางปฏิบัติที่พึงประสงค์

เราสนับสนุนและส่งเสริมให้สมาชิกทุกคน:

  • ปฏิบัติต่อผู้อื่นด้วยความเคารพ: สื่อสารอย่างสุภาพ ให้เกียรติความคิดเห็นที่แตกต่าง และรับฟังมุมมองของเพื่อนสมาชิก
  • แบ่งปันสิ่งที่เป็นประโยชน์: แลกเปลี่ยนข้อมูลเชิงวิชาการ ประสบการณ์การเรียน การใช้ชีวิตในรั้วมหาวิทยาลัย และกิจกรรมสร้างสรรค์
  • ร่วมกันดูแลสังคม: ช่วยเหลือผู้ใช้งานอื่น และใช้ฟังก์ชันรายงานเนื้อหาเมื่อพบเห็นการกระทำที่ไม่เหมาะสม

3. เนื้อหาและพฤติกรรมต้องห้ามทั่วไป

สิ่งต่อไปนี้ถือเป็นการกระทำที่ผิดกฎระเบียบชุมชนอย่างชัดเจน:

  • การคุกคามและการกลั่นแกล้ง (Harassment & Bullying): การด่าทอ เสียดสี เหยียดหยาม ข่มขู่ ก่อกวน สร้างความหวาดกลัว หรือจงใจกีดกันบุคคลอื่นออกจากสังคม
  • การละเมิดความเป็นส่วนตัว (Doxxing): การเปิดเผยข้อมูลส่วนบุคคล รูปถ่าย เบอร์โทรศัพท์ บัญชีโซเชียลมีเดีย หรือข้อมูลอื่นของผู้อื่นโดยไม่ได้รับความยินยอม เพื่อประจานหรือสร้างความเสียหาย
  • เนื้อหาลามกอนาจารและความรุนแรง: การส่งข้อความ รูปภาพ วิดีโอ หรือสื่อที่มีลักษณะลามก ยั่วยุทางเพศ สื่อการค้าประเวณี หรือภาพความรุนแรงและทารุณกรรม
  • คำพูดสร้างความเกลียดชัง (Hate Speech): การโจมตี ดูหมิ่น หรือสร้างความเกลียดชังต่อกลุ่มบุคคลโดยอ้างอิงจากเชื้อชาติ ศาสนา เพศ เพศวิถี ความพิการ หรือสถาบันการศึกษา
  • การสแปม โฆษณา และการหลอกลวง: การส่งข้อความซ้ำๆ รัวข้อความเพื่อป่วนห้อง การโฆษณาสินค้าหรือบริการโดยไม่ได้รับอนุญาต การชักชวนเล่นการพนัน หรือการหลอกลวงทางการเงินทุกรูปแบบ
  • เนื้อหาที่ผิดกฎหมาย: การซื้อขายสิ่งของผิดกฎหมาย สารเสพติด อาวุธ หรือการชักจูงให้กระทำความผิดตามกฎหมายแห่งราชอาณาจักรไทย

4. ข้อห้ามเด็ดขาดด้านเทคนิคและความมั่นคงปลอดภัยของระบบ

เพื่อปกป้องเสถียรภาพ ความปลอดภัยของระบบ และผู้ใช้งานส่วนรวม แพลตฟอร์มกำหนดข้อห้ามเด็ดขาดด้านเทคนิคดังนี้:

  • ห้ามใช้งาน API โดยไม่ได้รับอนุญาต (Unauthorized API Access): ห้ามเรียกใช้งาน เชื่อมต่อ ยิงคำขอ (Request) หรือใช้งาน API และ WebSocket ของระบบผ่านสคริปต์ ซอฟต์แวร์ บอท หรือเครื่องมืออัตโนมัติภายนอกโดยไม่ได้รับอนุญาตเป็นลายลักษณ์อักษร
  • ห้ามโจมตีระบบและ DDoS (DDoS & Flooding Attacks): ห้ามกระทำการใดๆ ที่เป็นการส่งข้อมูลจำนวนมหาศาลเพื่อทำให้เซิร์ฟเวอร์ เครือข่าย หรือบริการขัดข้อง ชะงัก หรือหยุดทำงาน รวมถึงการโจมตีแบบ Distributed Denial of Service (DDoS), Denial of Service (DoS) หรือการฟลัดข้อความ
  • ห้ามเจาะระบบหรือพยายามเข้าถึงโดยมิชอบ (Breach & Hacking Attempts): ห้ามพยายามค้นหาช่องโหว่ ทำการทดสอบเจาะระบบ (Penetration Testing) โดยไม่ได้รับอนุญาต แฮกระบบ แทรกแซงฐานข้อมูล ดัดแปลงข้อมูล หรือข้ามผ่านกลไกการรักษาความปลอดภัยของระบบ
  • ห้ามดูดหรือคัดลอกข้อมูลโดยอัตโนมัติ (Web Scraping): ห้ามใช้สไปเดอร์ (Spider), ครอว์เลอร์ (Crawler), บอท (Bot), สคริปต์สแครปปิง หรือกระบวนการอัตโนมัติใดๆ ในการดึง คัดลอก รวบรวม หรือกวาดข้อมูลข้อความสนทนา โปรไฟล์ผู้ใช้ หรือข้อมูลใดๆ จากแพลตฟอร์ม

การละเมิดข้อห้ามด้านเทคนิคข้างต้นจะส่งผลให้ถูกระงับการเข้าถึง ปิดกั้น IP อย่างถาวร และถูกดำเนินคดีตามพระราชบัญญัติว่าด้วยการกระทำความผิดเกี่ยวกับคอมพิวเตอร์อย่างถึงที่สุด

5. การใช้งานเป็นทางผ่านและการเชื่อมต่อไปยังบริการภายนอก

ลาน มหาวิทยาลัย ทำหน้าที่เป็นเพียงพื้นที่กลางและทางผ่าน (Transit / Pass-through Service) ในการสื่อสารระหว่างผู้ใช้งานเท่านั้น

  • ในกรณีที่มีการส่งต่อหรือแชร์ลิงก์เพื่อไปติดต่อกันต่อบนแพลตฟอร์มภายนอก (เช่น Facebook, Instagram, LINE, Discord หรือเว็บไซต์อื่นใด) ผู้ใช้งานต้องใช้วิจารณญาณและรับผิดชอบดูแลความปลอดภัยของตนเอง
  • แพลตฟอร์มไม่มีอำนาจควบคุม ไม่มีส่วนเกี่ยวข้อง และไม่รับผิดชอบทางกฎหมายต่อความเสียหาย ข้อพิพาท การฉ้อโกง หรือเหตุการณ์ใดๆ ที่เกิดขึ้นบนหรือผ่านบริการของบุคคลที่สามเหล่านั้น

6. การบันทึกข้อมูลจราจรทางคอมพิวเตอร์ตามกฎหมาย

เพื่อปฏิบัติตาม พระราชบัญญัติว่าด้วยการกระทำความผิดเกี่ยวกับคอมพิวเตอร์ พ.ศ. 2550 (และที่แก้ไขเพิ่มเติม) ระบบของเรามีการบันทึกและเก็บรักษาข้อมูลจราจรทางคอมพิวเตอร์ (Traffic Logs) ไว้อย่างเคร่งครัดเป็นระยะเวลา 90 วัน

ข้อมูลดังกล่าวจะถูกนำมาใช้เพื่อวัตถุประสงค์ในการตรวจสอบความปลอดภัย การป้องกันเหตุคุกคาม และใช้เป็นพยานหลักฐานในการดำเนินคดีทางกฎหมายแก่ผู้ที่ละเมิดกฎระเบียบหรือก่ออาชญากรรมทางคอมพิวเตอร์

7. การรายงานเนื้อหาและมาตรการลงโทษ

สมาชิกทุกคนสามารถช่วยดูแลสังคมได้โดยการกดปุ่มรายงานที่ข้อความสนทนา โดยมีหมวดหมู่การรายงานครอบคลุม: คำพูดเกลียดชัง, ลามกอนาจาร, สแปมและโฆษณา, แฉข้อมูลส่วนตัว, ป่วนห้องสนทนา และอื่นๆ

เมื่อพบการละเมิด ทีมงานจะพิจารณาลงโทษตามระดับความร้ายแรง ดังนี้:

  1. การตักเตือน (Warning): แจ้งเตือนอย่างเป็นทางการถึงพฤติกรรมที่ไม่เหมาะสม
  2. การระงับการใช้งานชั่วคราว (Suspension): พักการใช้งานบัญชีตามระยะเวลาที่กำหนด
  3. การระงับการใช้งานถาวร (Permanent Ban): ปิดกั้นบัญชี อุปกรณ์ หรือที่อยู่ไอพีอย่างถาวร
  4. การดำเนินคดีตามกฎหมาย: ในกรณีที่มีการละเมิดกฎหมาย การแฮกระบบ การคุกคามร้ายแรง หรือการกระทำความผิดทางอาญา ทีมงานจะส่งมอบหลักฐานแก่เจ้าหน้าที่ตำรวจเพื่อดำเนินคดี

8. การเปลี่ยนแปลงกฎระเบียบ

ทีมงานขอสงวนสิทธิ์ในการปรับปรุงหรือแก้ไขกฎระเบียบฉบับนี้ตามความเหมาะสม การที่ท่านยังคงใช้งานแพลตฟอร์มต่อไปหลังจากการปรับปรุง ถือว่าท่านยอมรับกฎระเบียบฉบับแก้ไขแล้ว
