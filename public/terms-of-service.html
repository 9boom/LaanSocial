ลาน ดอท โซเชียล

ศูนย์กลางแชทออนไลน์สำหรับนักเรียนและนักศึกษา รวมในที่เดียว

เงื่อนไขการใช้งาน

อัปเดตล่าสุด: กันยายน 2569

1. การยอมรับเงื่อนไขและข้อกำหนด

ยินดีต้อนรับสู่ ลาน ดอท โซเชียล ("แพลตฟอร์ม") พัฒนา ดูแล และให้บริการโดย Pongsakorn Sriwichai ("ผู้ให้บริการ") การเข้าถึง ลงทะเบียน เชื่อมต่อ หรือใช้งานส่วนใดส่วนหนึ่งของแพลตฟอร์มนี้ ถือว่าท่านได้อ่าน ทำความเข้าใจ และตกลงยินยอมผูกพันตามข้อกำหนดและเงื่อนไขการใช้งานฉบับนี้ รวมถึงนโยบายความเป็นส่วนตัวและกฎระเบียบชุมชนอย่างครบถ้วนโดยไม่มีข้อโต้แย้ง

หากท่านไม่เห็นด้วยหรือไม่ยอมรับข้อกำหนดเหล่านี้ ไม่ว่าทั้งหมดหรือบางส่วน กรุณายุติการเข้าถึงและหยุดใช้งานแพลตฟอร์มทันที

2. คุณสมบัติและความรับผิดชอบของผู้ใช้งาน

ผู้ใช้งานต้องมีคุณสมบัติตามเกณฑ์ดังต่อไปนี้:

  • มีอายุตั้งแต่ 13 ปีขึ้นไป
  • เป็นนักเรียน นักศึกษา บุคลากรทางการศึกษา หรือผู้ที่มีความประสงค์จะเข้าร่วมแลกเปลี่ยนข้อมูล ปรึกษารุ่นพี่ ติวหนังสือ หรือพูดคุยเชิงสร้างสรรค์ในสังคมการศึกษา
  • ไม่เคยถูกระงับการใช้งาน เพิกถอนบัญชี หรือถูกขึ้นบัญชีดำ (Blacklist) จากแพลตฟอร์มนี้มาก่อน
  • ท่านต้องรับผิดชอบต่อการกระทำ กิจกรรม การส่งข้อความ และผลลัพธ์ทั้งหมดที่เกิดขึ้นภายใต้บัญชีหรือโปรไฟล์ของท่าน

3. บัญชีผู้ใช้และลักษณะการให้บริการ

แพลตฟอร์มถูกออกแบบขึ้นโดยเน้นการสื่อสารแบบนามแฝง (Pseudonymous Communication) เพื่อความคล่องตัวและเป็นส่วนตัว:

  • ผู้ใช้สามารถเลือกตั้งชื่อเล่น สถาบันการศึกษา และรูปโปรไฟล์จากระบบได้ โดยชื่อเล่นสามารถกำหนดได้เพียงครั้งเดียวในขั้นตอนแรกและไม่สามารถแก้ไขหรือเปลี่ยนแปลงได้
  • การให้บริการประกอบด้วย ห้องสนทนาถาวร ประจำสถาบัน ซึ่งมีการจำกัดจำนวนข้อความสูงสุด 200 ข้อความต่อห้อง โดยข้อความที่เก่าที่สุดจะถูกลบออกโดยอัตโนมัติเมื่อมีข้อความใหม่เข้ามาเกินขีดจำกัดดังกล่าว และ ห้องสนทนาชั่วคราว (Temproom) ที่สร้างขึ้นตามหัวข้อเฉพาะกิจ ซึ่งจะหมดอายุตามระยะเวลาที่กำหนดเว้นแต่จะได้รับคะแนนโหวตให้อยู่ถาวร
  • ผู้ให้บริการขอสงวนสิทธิ์ในการปรับปรุง พัฒนา ระงับ หรือเปลี่ยนแปลงฟังก์ชันการให้บริการใดๆ ตามความเหมาะสมโดยไม่ต้องแจ้งให้ทราบล่วงหน้า

4. การให้บริการในลักษณะทางผ่านและการปฏิเสธความรับผิดต่อแพลตฟอร์มภายนอก

ลาน ดอท โซเชียล ให้บริการในฐานะพื้นที่กลางและทางผ่าน (Transit / Pass-through Service) สำหรับการสื่อสารเท่านั้น:

  • ผู้ใช้งานอาจมีการระบุลิงก์โปรไฟล์โซเชียลมีเดียส่วนบุคคล (Facebook หรือ Instagram) หรือแชร์ลิงก์เชื่อมต่อไปยังบริการของบุคคลที่สาม
  • ผู้ให้บริการไม่มีส่วนเกี่ยวข้อง ไม่ได้เป็นตัวแทน ไม่ได้รับรองความถูกต้อง ปลอดภัย หรือความน่าเชื่อถือ และไม่มีอำนาจควบคุมดูแลเนื้อหาหรือกิจกรรมใดๆ บนแพลตฟอร์มของบุคคลที่สามเหล่านั้น
  • ข้อจำกัดความรับผิดทางกฎหมาย: ผู้ให้บริการขอปฏิเสธความรับผิดชอบทางกฎหมายโดยสิ้นเชิงต่อความเสียหาย ความสูญเสีย ข้อพิพาท การฉ้อโกง การผิดสัญญา หรือความเสียหายต่อเนื่องใดๆ ทั้งทางตรงและทางอ้อม ที่เกิดขึ้นบนหรือผ่านการเชื่อมต่อไปยังแพลตฟอร์มของบุคคลที่สามจากการใช้บริการแพลตฟอร์มนี้เป็นทางผ่าน ผู้ใช้งานตกลงรับความเสี่ยงในการติดต่อและทำธุรกรรมภายนอกด้วยตนเองทั้งสิ้น

5. ข้อห้ามการใช้งานอย่างเด็ดขาดและมาตรการความมั่นคงปลอดภัย

เพื่อรักษาความปลอดภัย เสถียรภาพ และความสมบูรณ์ของระบบ ห้ามมิให้ผู้ใช้งานหรือบุคคลใดกระทำการดังต่อไปนี้โดยเด็ดขาด:

  • การใช้งาน API โดยไม่ได้รับอนุญาต (Unauthorized API Access): ห้ามเรียกใช้ ส่งคำขอ (Requests) เชื่อมต่อ หรือส่งคำสั่งไปยัง Application Programming Interface (API) หรือ WebSocket ของแพลตฟอร์มโดยตรงผ่านสคริปต์ ซอฟต์แวร์อัตโนมัติ หรือวิธีการอื่นใดที่มิได้กระทำผ่านอินเทอร์เฟซของแอปพลิเคชันอย่างเป็นทางการ รวมถึงการพยายามสร้างหรือปลอมแปลงโทเค็นและกุญแจตรวจสอบสิทธิ์ (Access Key) โดยมิชอบ
  • การโจมตีระบบและ DDoS (DDoS & DoS Attacks): ห้ามกระทำการใดๆ ที่เป็นการขัดขวาง หน่วง ทำลาย หรือทำให้เซิร์ฟเวอร์ เครือข่าย หรือบริการขัดข้อง ชะงักงัน หรือไม่สามารถให้บริการได้ตามปกติ รวมถึงการโจมตีแบบ Distributed Denial of Service (DDoS), Denial of Service (DoS), การฟลัดข้อมูล (Flooding) หรือการส่งข้อความสแปมปริมาณมหาศาล
  • การพยายามเจาะระบบและเข้าถึงข้อมูลโดยมิชอบ (Breach & Hacking Attempts): ห้ามพยายามค้นหาช่องโหว่ ทำการทดสอบเจาะระบบ (Penetration Testing) โดยไม่ได้รับอนุญาต แฮกระบบ แทรกแซง ดัดแปลง ทำลายฐานข้อมูล หรือพยายามเข้าถึงบัญชี ข้อมูล และโครงสร้างพื้นฐานของผู้ให้บริการและผู้ใช้อื่น
  • การดูดข้อมูลและการทำเหมืองข้อมูล (Web Scraping): ห้ามใช้โปรแกรมอัตโนมัติ บอท (Bot), สไปเดอร์ (Spider), ครอว์เลอร์ (Crawler), สคริปต์สกัดข้อมูล หรือเทคโนโลยีใดๆ ในการดึง รวบรวม ทำซ้ำ หรือคัดลอกข้อความสนทนา รายชื่อสถาบัน ข้อมูลโปรไฟล์ หรือเนื้อหาใดๆ บนแพลตฟอร์ม

6. เนื้อหาของผู้ใช้งานและทรัพย์สินทางปัญญา

ผู้ใช้งานรับรองว่าเนื้อหา ข้อความ ภาพ และไฟล์ที่ตนเผยแพร่บนแพลตฟอร์มเป็นสิ่งที่ตนมีสิทธิถูกต้องตามกฎหมาย และไม่ละเมิดลิขสิทธิ์ เครื่องหมายการค้า หรือสิทธิในทรัพย์สินทางปัญญาของบุคคลภายนอก

ลิขสิทธิ์ ซอร์สโค้ด ตราสัญลักษณ์ โลโก้ งานออกแบบ อินเทอร์เฟซ และองค์ประกอบทั้งหมดของแพลตฟอร์ม ถือเป็นทรัพย์สินทางปัญญาของผู้ให้บริการแต่เพียงผู้เดียว ห้ามมิให้ผู้ใดทำซ้ำ ดัดแปลง เผยแพร่ หรือนำไปใช้ประโยชน์ในเชิงพาณิชย์โดยมิได้รับความยินยอมเป็นลายลักษณ์อักษร

7. การปฏิเสธการรับประกันและการจำกัดความรับผิดทั่วไป

แพลตฟอร์มนี้ให้บริการ "ตามสภาพที่เป็นอยู่" (As-Is) และ "ตามที่มีให้ใช้งาน" (As-Available) โดยไม่มีการรับประกัน ไม่ว่าโดยชัดแจ้งหรือโดยปริยายในเรื่องความต่อเนื่อง การปราศจากข้อผิดพลาด หรือความเหมาะสมสำหรับวัตถุประสงค์เฉพาะด้าน

ผู้ให้บริการไม่ต้องรับผิดต่อความเสียหาย ความสูญเสียของข้อมูล ความล่าช้า หรือความขัดข้องของระบบเครือข่ายที่อยู่นอกเหนือการควบคุมตามสมควร

8. การสิ้นสุดการให้บริการและการระงับบัญชี

ผู้ใช้งานสามารถขอยกเลิกบัญชีและยุติการใช้งานได้ตลอดเวลาผ่านเมนูการตั้งค่าของแอปพลิเคชัน

ในกรณีที่พบว่ามีการละเมิดเงื่อนไขการใช้งานหรือกฎระเบียบชุมชน ทีมงานจะดำเนินการระงับการใช้งานบัญชีชั่วคราว และหากพบการกระทำผิดซ้ำจะดำเนินการระงับการใช้งานอย่างถาวร ทั้งนี้ สำหรับการดำเนินคดีทางกฎหมาย ผู้ให้บริการจะดำเนินการส่งมอบข้อมูลและให้ความร่วมมือเมื่อได้รับการร้องขออย่างเป็นทางการจากเจ้าหน้าที่ตำรวจตามกฎหมายเท่านั้น

9. การเปลี่ยนแปลงเงื่อนไขและกฎหมายที่ใช้บังคับ

ผู้ให้บริการอาจแก้ไข ปรับปรุง หรือเพิ่มเติมข้อกำหนดในเงื่อนไขการใช้งานนี้ได้ตลอดเวลา โดยจะระบุวันที่อัปเดตไว้ด้านบน การที่ท่านยังคงใช้งานแพลตฟอร์มอย่างต่อเนื่องภายหลังการปรับปรุง ถือว่าท่านได้รับทราบและยอมรับเงื่อนไขฉบับแก้ไขดังกล่าวแล้ว

เงื่อนไขการใช้งานฉบับนี้อยู่ภายใต้การบังคับใช้และตีความตามกฎหมายแห่งราชอาณาจักรไทย
